## 學習目標

- 能在二、八、十、十六進位之間互相轉換，包含小數部分。
- 會求 $r$ 的補數與 $(r-1)$ 的補數，並用補數做減法。
- 能用符號大小、1 的補數、2 的補數三種方式表示負數，並判斷溢位。
- 會做 BCD 加法，並說明格雷碼、ASCII 與同位元的用途。

## 數位系統與二進位

數位系統處理的是離散（discrete）的資訊：訊號只取有限幾種值。類比訊號則可以取連續範圍內的任何值。把類比訊號變成數位訊號要經過兩步：取樣（sampling）決定「多久記一次」，量化（quantization）決定「每次記到多細」。

實際電路幾乎都用二進位，因為只要分辨「高電位」與「低電位」兩種狀態，抗雜訊能力最好。0／1 也可以解讀成 False／True、Low／High、Off／On，本質相同。

## 進位制與位值記號

### 位值記號

以 $r$ 為基底（radix）的數，每一位的係數 $a_j$ 介於 $0$ 到 $r-1$，數值是每一位乘上對應的 $r$ 次方再加總：

$$(a_n \cdots a_1 a_0 . a_{-1} \cdots a_{-m})_r = \sum_{j=-m}^{n} a_j \, r^{j}$$

::: example 轉成十進位
$$(10110.101)_2 = 16 + 4 + 2 + 0.5 + 0.125 = (22.625)_{10}$$

$$(3\text{A}7.\text{C})_{16} = 3 \times 256 + 10 \times 16 + 7 + \tfrac{12}{16} = (935.75)_{10}$$

十六進位的 A–F 代表 10–15。
:::

常用的二的次方要記熟：$2^{10} = 1024$ 記作 K，$2^{20}$ 記作 M，$2^{30}$ 記作 G。

### 十進位轉成 $r$ 進位

整數和小數部分**分開處理**：

- **整數**：反覆除以 $r$，記下餘數，直到商為 0。餘數**由下往上**讀。
- **小數**：反覆乘以 $r$，記下整數部分，再拿剩下的小數繼續乘。整數部分**由上往下**讀。

::: example $(58.8125)_{10}$ 轉二進位
整數部分：

| 運算 | 商 | 餘數 |
| :-: | :-: | :-: |
| $58 \div 2$ | 29 | 0 |
| $29 \div 2$ | 14 | 1 |
| $14 \div 2$ | 7 | 0 |
| $7 \div 2$ | 3 | 1 |
| $3 \div 2$ | 1 | 1 |
| $1 \div 2$ | 0 | 1 |

由下往上讀得 $111010$。

小數部分：$0.8125 \times 2 = 1.625$ → 1；$0.625 \times 2 = 1.25$ → 1；$0.25 \times 2 = 0.5$ → 0；$0.5 \times 2 = 1.0$ → 1。由上往下讀得 $.1101$。

合起來：$(58.8125)_{10} = (111010.1101)_2$。
:::

::: warning 小數不一定除得盡
$(0.3)_{10}$ 轉八進位時，乘 8 的整數部分依序是 2、3、1、4、6…，永遠不會停。題目會指定要算到幾位，例如 $(0.3)_{10} \approx (0.2314)_8$。
:::

### 二、八、十六進位互轉

$8 = 2^3$、$16 = 2^4$，所以不必經過十進位：從小數點開始往左、往右，**每 3 位一組換成八進位，每 4 位一組換成十六進位**，不足的位數補 0。

$$(1011101.0111)_2 = (\underbrace{001}_{1}\,\underbrace{011}_{3}\,\underbrace{101}_{5}.\underbrace{011}_{3}\,\underbrace{100}_{4})_2 = (135.34)_8$$

$$(1011101.0111)_2 = (\underbrace{0101}_{5}\,\underbrace{1101}_{\text{D}}.\underbrace{0111}_{7})_2 = (5\text{D}.7)_{16}$$

反方向只要把每一位展開成 3 或 4 個位元即可。

## 補數與減法

### 兩種補數

$n$ 位數的 $r$ 進位數 $N$ 有兩種補數：

::: definition $(r-1)$ 的補數與 $r$ 的補數
- $(r-1)$ 的補數（diminished radix complement）：$(r^n - 1) - N$。實際做法是每一位用 $r-1$ 去減。
- $r$ 的補數（radix complement）：$r^n - N$（$N \neq 0$），等於 $(r-1)$ 的補數再加 1。
:::

| 數 | 9 的補數 | 10 的補數 |
| :-: | :-: | :-: |
| 04512 | 95487 | 95488 |

| 數 | 1 的補數 | 2 的補數 |
| :-: | :-: | :-: |
| 1011000 | 0100111 | 0101000 |

::: tip 2 的補數速算
從最右邊往左找到**第一個 1**，這個 1 和它右邊的 0 都不變，左邊的位元全部反相。例如 $1011000$：最右邊的 1 在第 3 位，保留 $1000$，前面 $101$ 反相成 $010$，得 $0101000$。
:::

### 用補數做減法

計算 $M - N$（兩者都是 $n$ 位無號數）：把 $M$ 加上 $N$ 的 $r$ 的補數。

- **有進位**（end carry）：丟掉進位，結果就是 $M - N$。
- **沒有進位**：代表 $M < N$，答案是「和的 $r$ 的補數」再加上負號。

::: example 用 10 的補數算 63845 − 02471 與 02471 − 63845
$63845 + 97529 = 1\,61374$，有進位，丟掉得 $61374$。

$02471 + 36155 = 38626$，沒有進位，答案是 $-(38626 \text{ 的 10 的補數}) = -61374$。
:::

::: example 用 2 的補數算 $X - Y$，$X = 1100101$、$Y = 0110110$
$Y$ 的 2 的補數是 $1001010$。$X + 1001010 = 1\,0101111$，有進位，丟掉得 $0101111 = (47)_{10}$。

驗算：$X = 101$、$Y = 54$，$101 - 54 = 47$。
:::

用 $(r-1)$ 的補數也可以做減法，差別是**有進位時要把進位加回最低位**（end-around carry）。上例改用 1 的補數：$1100101 + 1001001 = 1\,0101110$，進位加回去得 $0101110 + 1 = 0101111$。

## 有號二進位數

### 三種表示法

最左邊一位當作符號位元：0 表示正，1 表示負。正數三種表示法都一樣，負數則不同。以 8 位元表示 $-13$：

| 表示法 | $-13$ | 做法 |
| --- | :-: | --- |
| 符號大小（signed magnitude） | 10001101 | 符號位元改成 1，大小不變 |
| 1 的補數（signed 1's complement） | 11110010 | $+13$ 全部反相 |
| 2 的補數（signed 2's complement） | 11110011 | $+13$ 取 2 的補數 |

電腦幾乎都用 2 的補數，因為它只有一個 0，加減法也不需要另外處理符號。$n$ 位元 2 的補數的範圍是 $-2^{n-1}$ 到 $2^{n-1} - 1$，例如 4 位元是 $-8$ 到 $+7$。

### 2 的補數加減法

- **加法**：連同符號位元直接相加，符號位元產生的進位丟掉。
- **減法**：把減數取 2 的補數（含符號位元），再做加法。

::: example 8 位元 2 的補數運算
$(+9) + (-5)$：$00001001 + 11111011 = 1\,00000100$，丟掉進位得 $+4$。

$(-9) - (-14) = (-9) + (+14)$：$11110111 + 00001110 = 1\,00000101$，丟掉進位得 $+5$。
:::

::: warning 溢位（overflow）
結果超出可表示範圍時答案會錯。4 位元 $(+5) + (+6)$：$0101 + 0110 = 1011$，兩個正數相加卻得到負數。判斷方式：**兩個同號的數相加，結果卻變號**，就是溢位。第 4 章的加法器會用電路偵測它。
:::

## 二進位編碼

### BCD 碼

BCD（binary-coded decimal）把每個十進位數字各用 4 位元表示。$295$ 的 BCD 是 $0010\;1001\;0101$，共 12 位元；它的二進位卻是 $100100111$，兩者不同。$1010$ 到 $1111$ 在 BCD 中沒有意義。

::: definition BCD 加法規則
逐位（每 4 位元）相加，若某一位的和**大於 9 或產生進位**，就再加 $6 = 0110$ 修正，修正產生的進位傳給下一位。
:::

::: example $457 + 368$
- 個位：$0111 + 1000 = 1111$（15 > 9），加 $0110$ 得 $1\,0101$，留 $0101$，進位 1。
- 十位：$0101 + 0110 + 1 = 1100$（12 > 9），加 $0110$ 得 $1\,0010$，留 $0010$，進位 1。
- 百位：$0100 + 0011 + 1 = 1000$（8），不用修正。

結果 $1000\;0010\;0101 = 825$。
:::

除了 BCD（又稱 8421 碼），課本還列出 2421 碼、超 3 碼（excess-3，每個數字的 BCD 再加 3）與 8,4,−2,−1 碼。2421 碼與超 3 碼是自補碼（self-complementing）：把碼字每一位反相，剛好得到該數字對 9 的補數。

### 格雷碼

格雷碼（Gray code）相鄰兩個數只差一個位元，用在旋轉編碼器等場合，可以避免多個位元同時變化造成的暫態錯誤，也是卡諾圖排列格子的依據。

建構方式是**鏡射**：$n$ 位元格雷碼 = 前面補 0 的 $(n-1)$ 位元格雷碼，接上「上下顛倒後前面補 1」的同一組碼。例如 2 位元：00、01、11、10。

::: tip 二進位與格雷碼互轉
- 二進位 → 格雷碼：最高位不變，其餘每一位 = 這一位 $\oplus$ 左邊那一位。$1011 \to 1110$。
- 格雷碼 → 二進位：最高位不變，其餘每一位 = 這一位格雷碼 $\oplus$ **剛算出的**左邊那一位二進位。$1101 \to 1001$。
:::

### ASCII 字元碼

ASCII 用 7 位元表示 128 個字元：94 個可列印字元與 34 個控制字元。幾個好用的規律：

- 數字 0–9 是 $30_{16}$ 到 $39_{16}$，減去 $30_{16}$ 就是數值。
- 大寫 A–Z 是 $41_{16}$ 到 $5\text{A}_{16}$，小寫 a–z 是 $61_{16}$ 到 $7\text{A}_{16}$。大小寫只差 $20_{16}$，也就是翻轉一個位元即可互換。

### 同位元

同位元（parity bit）是額外加上的一個位元，讓整個碼字中 1 的個數變成偶數（偶同位）或奇數（奇同位）。接收端重新數 1 的個數，就能偵測**單一位元錯誤**，但無法知道錯在哪一位，也抓不到偶數個位元同時出錯。

例：字母 C 的 ASCII 是 $1000011$，有三個 1。偶同位要補 1 成為 $1\,1000011$，奇同位要補 0 成為 $0\,1000011$。

## 暫存器與二進位邏輯

能穩定保存兩種狀態之一的元件叫做二進位記憶單元（binary cell），一組 $n$ 個記憶單元稱為暫存器（register），可以表示 $2^n$ 種狀態。資料在暫存器之間搬移稱為暫存器傳送（register transfer），是數位系統最基本的操作之一。暫存器的細節在 [第 7 單元](07-registers-counters.html)。

另一類元件負責處理位元：AND、OR、NOT 等邏輯閘。它們的定義與代數規則在 [第 2 單元](02-boolean-algebra.html)。

## 重點整理

- 十進位轉 $r$ 進位：整數反覆除、餘數由下往上；小數反覆乘、整數部分由上往下。
- 二轉八、二轉十六：從小數點往兩側每 3 位、每 4 位一組。
- $(r-1)$ 的補數是每位用 $r-1$ 去減，$r$ 的補數再加 1。
- 補數減法：有進位就丟掉（用 $(r-1)$ 的補數時要加回），沒進位代表結果為負，要再取補數加負號。
- 2 的補數只有一個 0，範圍 $-2^{n-1}$ 到 $2^{n-1}-1$；同號相加結果變號就是溢位。
- BCD 加法每位超過 9 或有進位就加 6 修正。
- 格雷碼相鄰只差一位；同位元能偵測單一位元錯誤。

## 練習題

:::: exercise 把 $(2\text{C}.4)_{16}$ 轉成十進位與二進位
::: answer
十進位：$2 \times 16 + 12 + 4 \times 16^{-1} = 32 + 12 + 0.25 = (44.25)_{10}$。

二進位：每一位十六進位直接展開成 4 位元，$2 \to 0010$、$\text{C} \to 1100$、$4 \to 0100$，得 $(00101100.0100)_2 = (101100.01)_2$。

驗算：$32 + 8 + 4 + 0.25 = 44.25$。
:::
::::

:::: exercise 用 2 的補數計算 $0110101 - 1011000$（兩者皆為 7 位元無號數）
::: answer
減數 $1011000$ 的 2 的補數是 $0101000$。

$$0110101 + 0101000 = 1011101$$

沒有進位，表示結果為負，答案是 $-(1011101 \text{ 的 2 的補數}) = -0100011$。

驗算：$0110101 = 53$、$1011000 = 88$，$53 - 88 = -35$，而 $0100011 = 35$。
:::
::::

:::: exercise 用 8 位元表示 $-27$ 的三種有號表示法，並用 2 的補數計算 $(+19) + (-27)$
::: answer
$+27 = 00011011$。

- 符號大小：$10011011$
- 1 的補數：$11100100$
- 2 的補數：$11100101$

$(+19) + (-27)$：$00010011 + 11100101 = 11111000$，沒有進位要丟。$11111000$ 的符號位元是 1，取 2 的補數得 $00001000 = 8$，所以結果是 $-8$，正確。
:::
::::

:::: exercise 用 BCD 計算 $389 + 247$
::: answer
- 個位：$1001 + 0111 = 1\,0000$（16，有進位），加 $0110$ 得 $1\,0110$，留 $0110$，進位 1。
- 十位：$1000 + 0100 + 1 = 1101$（13 > 9），加 $0110$ 得 $1\,0011$，留 $0011$，進位 1。
- 百位：$0011 + 0010 + 1 = 0110$（6），不用修正。

結果 $0110\;0011\;0110 = 636$。注意個位雖然結果 $0000$ 看起來不大於 9，但已經產生進位，仍然要修正。
:::
::::

:::: exercise 把二進位 $1100$ 轉成格雷碼，並把格雷碼 $0110$ 轉回二進位
::: answer
二進位 $1100$ → 格雷碼：最高位 1；$1 \oplus 1 = 0$；$0 \oplus 1 = 1$；$0 \oplus 0 = 0$，得 $1010$。

格雷碼 $0110$ → 二進位：最高位 0；$1 \oplus 0 = 1$；$1 \oplus 1 = 0$；$0 \oplus 0 = 0$，得 $0100$。

驗算：二進位 $0100$ 轉格雷碼是 $0\,(0 \oplus 1)\,(1 \oplus 0)\,(0 \oplus 0) = 0110$。
:::
::::
