## 學習目標

- 能說明組合電路與循序電路、同步與非同步的差別。
- 能分析 SR 閂鎖（NOR 與 NAND 兩種）與 D 閂鎖的行為，說明閂鎖為何不適合直接接時脈。
- 會寫出 D、JK、T 正反器的特性表與特性方程式，說明建立時間與保持時間。
- 能從同步循序電路推出輸入方程式、狀態方程式、狀態表與狀態圖。
- 能分辨 Mealy 與 Moore 兩種狀態機。

## 循序電路是什麼

組合電路的輸出只由**當下的輸入**決定，沒有記憶。循序電路（sequential circuit）則多了記憶元件，輸出由**輸入和目前狀態**共同決定，而下一個狀態也由輸入和目前狀態決定。

$$\text{(輸入, 目前狀態)} \longrightarrow \text{(輸出, 下一個狀態)}$$

依狀態改變的時機分成兩類：

- **同步**（synchronous）：狀態只在時脈（clock）的特定時刻改變，所有記憶元件看同一個時脈。容易設計、容易驗證，是本課程的重點。
- **非同步**（asynchronous）：輸入一變，狀態隨時可能跟著變，設計時要處理競跑等時序問題。

同步電路使用的記憶元件是正反器（flip-flop）。它的基本構造是閂鎖（latch）。

## 閂鎖

### 用回授保存一個位元

兩個反相器頭尾相接，就有兩個穩定狀態：一邊是 0、另一邊是 1，會一直維持下去。問題是無法從外部改變它。把反相器換成 NOR 或 NAND，多出來的輸入就能用來設定狀態。

### SR 閂鎖（NOR 構成）

兩個 NOR 交叉相接，輸入 $S$（set）與 $R$（reset）：

| $S$ | $R$ | $Q$ 的下一個值 | 說明 |
| :-: | :-: | :-: | --- |
| 0 | 0 | $Q$ | 保持 |
| 0 | 1 | 0 | 重置 |
| 1 | 0 | 1 | 設定 |
| 1 | 1 | — | 禁止：$Q$ 與 $\inv{Q}$ 同時為 0 |

$S = R = 1$ 時兩個輸出都被拉成 0，違反「$Q$ 與 $\inv{Q}$ 互補」；若兩個輸入接著同時回到 0，下一個狀態無法預測。所以正常使用時要避免 $S = R = 1$。

### $\inv{S}\,\inv{R}$ 閂鎖（NAND 構成）

改用兩個 NAND 交叉相接，輸入變成**低態有效**（active low）：$\inv{S} = 0$ 設定、$\inv{R} = 0$ 重置、兩者都是 1 時保持，兩者同時為 0 是禁止狀態。行為與 NOR 版本相同，只是輸入的意義反過來。

::: warning NOR 與 NAND 版本的禁止組合不同
NOR 版本禁止 $S = R = 1$，NAND 版本禁止 $\inv{S} = \inv{R} = 0$。看到題目先確認是哪一種，以及輸入是高態還是低態有效。
:::

### 有控制輸入的閂鎖與 D 閂鎖

在 SR 閂鎖前面加一組 NAND 與致能輸入 $En$：$En = 0$ 時不論 $S, R$ 為何都保持，$En = 1$ 時才照 $S, R$ 動作。

再把 $R$ 接成 $\inv{S}$，就成為 D 閂鎖（D latch），只剩一個資料輸入 $D$，從根本上消除禁止狀態：

- $En = 1$：$Q$ 跟著 $D$ 變，像一條透明的線，所以又叫透明閂鎖（transparent latch）。
- $En = 0$：$Q$ 保持 $En$ 下降前最後的值。

::: warning 閂鎖為什麼不能直接接時脈
閂鎖是**準位觸發**（level-sensitive）。時脈為 1 的整段期間它都是透明的，若輸出經過組合電路又回到自己的輸入，狀態會在同一個時脈期間內被改好幾次。正反器改成**邊緣觸發**（edge-triggered），每個時脈只在上升緣或下降緣改變一次，才能正確組成同步電路。
:::

## 正反器

### 邊緣觸發 D 正反器

兩種常見構造：

- **主從式**（master-slave）：兩個 D 閂鎖串接，致能訊號一個接 $Clk$、一個接 $\inv{Clk}$。時脈為高時主閂鎖透明、從閂鎖鎖住；時脈下降的瞬間主閂鎖鎖住，從閂鎖把值傳到輸出。整體看起來就是**負緣觸發**。
- **三個 SR 閂鎖**：用三個 NAND 型閂鎖組成的正緣觸發 D 正反器。時脈為 0 時兩個內部閂鎖的輸出都是 1，輸出閂鎖保持；時脈上升的瞬間依 $D$ 設定或重置輸出閂鎖；時脈維持為 1 時，$D$ 再怎麼變也不影響輸出。

不論哪種構造，正反器都有兩個時間限制：

::: definition 建立時間與保持時間
- 建立時間（setup time）：時脈觸發邊緣**之前**，$D$ 必須維持穩定的最短時間。
- 保持時間（hold time）：時脈觸發邊緣**之後**，$D$ 必須維持穩定的最短時間。

違反任一個，正反器可能取到錯的值，甚至進入介穩態。
:::

### 三種正反器的特性

以 $Q(t)$ 表示目前狀態，$Q(t+1)$ 表示下一個時脈邊緣後的狀態：

| 正反器 | 特性表 | 特性方程式 |
| --- | --- | :-: |
| D | $D = 0 \to 0$；$D = 1 \to 1$ | $Q(t+1) = D$ |
| JK | $00$ 保持；$01$ 重置；$10$ 設定；$11$ 反相 | $Q(t+1) = J\inv{Q} + \inv{K}Q$ |
| T | $T = 0$ 保持；$T = 1$ 反相 | $Q(t+1) = T \oplus Q$ |

JK 正反器把 SR 的禁止狀態 $11$ 改成「反相」，可以用 D 正反器加上組合電路 $D = J\inv{Q} + \inv{K}Q$ 做出來。T 正反器則是 JK 把兩個輸入接在一起（$J = K = T$）。

### 直接輸入

有些正反器另外有非同步的預設（preset）與清除（clear）輸入，不管時脈和資料輸入，直接把輸出設成 1 或 0。最常見的用途是開機時把整個電路重置到已知狀態。這類輸入通常是低態有效。

## 同步循序電路的分析

分析就是「看電路、推行為」，步驟固定：

1. 寫出每個正反器的**輸入方程式**（input equation），例如 $D_A = \ldots$，以及電路的**輸出方程式**。
2. 把輸入方程式代入特性方程式，得到**狀態方程式**（state equation）$A(t+1) = \ldots$。
3. 列出**狀態表**（state table）：每一種「目前狀態 × 輸入」對應的下一個狀態與輸出。
4. 畫出**狀態圖**（state diagram）：圓圈是狀態，箭頭是轉移，箭頭上標「輸入／輸出」。

### 用 D 正反器的電路

D 正反器的下一個狀態就等於 $D$，所以輸入方程式直接就是狀態方程式。

::: example 兩個 D 正反器 $A, B$，輸入 $x$，輸出 $y$
$$D_A = A\inv{B} + Bx, \qquad D_B = \inv{A}x, \qquad y = A\inv{x}$$

狀態方程式：$A(t+1) = A\inv{B} + Bx$，$B(t+1) = \inv{A}x$。逐一代入四種狀態與兩種輸入：

| 目前 $AB$ | $x = 0$：下一個 $AB$ | $x = 0$：$y$ | $x = 1$：下一個 $AB$ | $x = 1$：$y$ |
| :-: | :-: | :-: | :-: | :-: |
| 00 | 00 | 0 | 01 | 0 |
| 01 | 00 | 0 | 11 | 0 |
| 10 | 10 | 1 | 10 | 0 |
| 11 | 00 | 1 | 10 | 0 |

狀態圖上，從 00 出發：輸入 1 走到 01（標 1/0），再輸入 1 走到 11（1/0），再輸入 1 走到 10（1/0）。到了 10 之後，輸入 1 留在原地（1/0），輸入 0 也留在原地但輸出 1（0/1）。
:::

### 用 JK 或 T 正反器的電路

JK 與 T 的下一個狀態不等於輸入，多一步：把輸入方程式代入特性方程式。

::: example JK 正反器電路
$$J_A = B, \quad K_A = B\inv{x}, \quad J_B = \inv{x}, \quad K_B = Ax$$

代入 $Q(t+1) = J\inv{Q} + \inv{K}Q$：

$$A(t+1) = B\inv{A} + \inv{B\inv{x}}\,A = \inv{A}B + A\inv{B} + Ax$$

$$B(t+1) = \inv{x}\,\inv{B} + \inv{Ax}\,B = \inv{B}\,\inv{x} + \inv{A}B + B\inv{x}$$

狀態表（沒有輸出）：

| 目前 $AB$ | $x = 0$ | $x = 1$ |
| :-: | :-: | :-: |
| 00 | 01 | 00 |
| 01 | 11 | 11 |
| 10 | 11 | 10 |
| 11 | 01 | 10 |

也可以不寫狀態方程式，直接逐列看 $J, K$ 的值再套特性表，對小電路往往更快。例如 $AB = 11, x = 0$：$J_A = 1, K_A = 1$，$A$ 反相成 0；$J_B = 1, K_B = 0$，$B$ 設定為 1，下一個狀態是 01。
:::

## Mealy 與 Moore 狀態機

::: definition 兩種有限狀態機
- Mealy 機：輸出由**目前狀態和輸入**決定。狀態圖上輸出標在箭頭上（輸入／輸出）。
- Moore 機：輸出**只由目前狀態**決定。狀態圖上輸出標在圓圈內（狀態／輸出）。
:::

前面 D 正反器的例子 $y = A\inv{x}$ 含有輸入，是 Mealy 機。若輸出方程式只含正反器變數，例如 $y = AB$，就是 Moore 機。

::: warning Mealy 輸出可能在時脈之間跳動
Mealy 機的輸出直接受輸入影響，輸入在兩個時脈邊緣之間改變時，輸出也會跟著變，可能出現短暫的錯誤值。實務上通常只在時脈邊緣附近讀取 Mealy 輸出，或在輸出端再加一級正反器。Moore 機的輸出只隨狀態改變，與時脈同步。
:::

## 重點整理

- 循序電路 = 組合電路 + 記憶元件；同步電路的狀態只在時脈邊緣改變。
- NOR 型 SR 閂鎖禁止 $S = R = 1$；NAND 型輸入低態有效，禁止 $\inv{S} = \inv{R} = 0$。
- D 閂鎖是準位觸發，時脈為高時透明；正反器是邊緣觸發，每個時脈只變一次。
- 特性方程式：D 是 $Q^+ = D$，JK 是 $Q^+ = J\inv{Q} + \inv{K}Q$，T 是 $Q^+ = T \oplus Q$。
- 分析流程：輸入方程式 → 狀態方程式 → 狀態表 → 狀態圖。
- Mealy 輸出看狀態和輸入，Moore 輸出只看狀態。

## 練習題

:::: exercise NOR 型 SR 閂鎖初始 $Q = 0$，依序輸入 $(S, R) = (1,0), (0,0), (0,1), (0,0), (1,1)$，寫出每一步的 $Q$ 與 $\inv{Q}$
::: answer
| 步驟 | $S$ | $R$ | $Q$ | $\inv{Q}$ | 說明 |
| :-: | :-: | :-: | :-: | :-: | --- |
| 1 | 1 | 0 | 1 | 0 | 設定 |
| 2 | 0 | 0 | 1 | 0 | 保持 |
| 3 | 0 | 1 | 0 | 1 | 重置 |
| 4 | 0 | 0 | 0 | 1 | 保持 |
| 5 | 1 | 1 | 0 | 0 | 禁止狀態：兩個輸出都是 0 |

第 5 步之後若 $S, R$ 同時回到 0，兩個 NOR 會互相競爭，結果無法預測。
:::
::::

:::: exercise 只有 D 正反器時，怎麼做出 T 正反器？寫出 $D$ 的方程式
::: answer
T 正反器的特性方程式是 $Q(t+1) = T \oplus Q$，D 正反器是 $Q(t+1) = D$。令兩者相等：

$$D = T \oplus Q = T\inv{Q} + \inv{T}Q$$

所以在 D 正反器前面加一個 XOR 閘，輸入接 $T$ 與正反器自己的輸出 $Q$。
:::
::::

:::: exercise 兩個 T 正反器，$T_A = Bx$、$T_B = x$，輸出 $y = AB$。列出狀態表，並判斷這是 Mealy 還是 Moore 機
::: answer
代入 $Q(t+1) = T \oplus Q$：$A(t+1) = A \oplus Bx$，$B(t+1) = B \oplus x$。

| 目前 $AB$ | $x = 0$ | $x = 1$ | $y$ |
| :-: | :-: | :-: | :-: |
| 00 | 00 | 01 | 0 |
| 01 | 01 | 10 | 0 |
| 10 | 10 | 11 | 0 |
| 11 | 11 | 00 | 1 |

$x = 0$ 時狀態不變，$x = 1$ 時依 00 → 01 → 10 → 11 → 00 遞增，是一個有致能輸入的 2 位元二進位計數器。輸出 $y = AB$ 只由狀態決定，所以是 Moore 機，計數到 11 時輸出 1。
:::
::::
