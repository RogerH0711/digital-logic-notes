## 學習目標

- 能畫出 2–4 變數的卡諾圖，並說明格子為什麼依格雷碼排列。
- 會依規則圈出合法的圈，並把每一圈讀成乘積項。
- 能分辨質蘊含項與必要質蘊含項，找出最簡 SOP。
- 會利用無關項讓結果更簡單，並用圈 0 的方式求最簡 POS。
- 會把最簡式轉成只用 NAND 或只用 NOR 的電路，並認得 AOI／OAI 等兩層形式。
- 能說明 XOR 的性質，設計同位元產生器與檢查器。

## 為什麼需要卡諾圖

上一單元用定理化簡時，關鍵一步常常是把兩個「只差一個變數」的項合併：

$$A\inv{B}C + ABC = AC(\inv{B} + B) = AC$$

兩個最小項只差一個位元時，就能合併並消掉那個變數。問題是變數一多，很難一眼看出哪些項只差一個位元。卡諾圖（Karnaugh map, K-map）的做法是把真值表重新排成格子，讓**只差一個位元的最小項在圖上剛好相鄰**，合併就變成「把相鄰的 1 圈起來」。

## 卡諾圖的畫法

### 格雷碼排列

三變數卡諾圖把 $A$ 放在列、$BC$ 放在欄。欄的順序不是 00、01、10、11，而是格雷碼（Gray code）00、01、11、10，相鄰兩欄只差一個位元。最左欄和最右欄（00 與 10）也只差一個位元，所以圖的左右邊界是**接在一起**的。

下圖是上一單元的多數決函數 $F = \sum m(3,5,6,7)$。每格右上角的小數字是最小項編號：

```kmap
vars: [A, B, C]
ones: [3, 5, 6, 7]
caption: 多數決函數，還沒有圈。注意欄的順序是 00、01、11、10。
```

### 圈起來並讀出乘積項

把相鄰的 1 圈起來，每一圈讀成一個乘積項：**圈內保持不變的變數留下，有變化的變數消掉**。

```kmap
vars: [A, B, C]
ones: [3, 5, 6, 7]
groups:
  - [3, 7]
  - [5, 7]
  - [6, 7]
caption: 三個圈都用到 $m_7$，重複圈是允許的。
```

以綠色的圈 $[3, 7]$ 為例：$m_3 = 011$、$m_7 = 111$，$A$ 從 0 變 1 被消掉，$B = 1$、$C = 1$ 不變，所以讀成 $BC$。

### 圈法規則

1. 每一圈的格數必須是 $2^k$（1、2、4、8…），而且形狀是矩形。
2. 圈 $2^k$ 格會消掉 $k$ 個變數，所以**圈越大，項越短**。
3. 圈可以跨越邊界：左右邊界相接，四變數時上下邊界也相接，四個角落也彼此相鄰。
4. 每個 1 至少被圈一次；可以重複圈，但每一圈都要有存在的理由。
5. 在能蓋住所有 1 的前提下，圈的數量越少越好。

::: example 四個角落是同一圈
四變數卡諾圖的列是 $AB$、欄是 $CD$，兩個方向都用格雷碼。$F = \sum m(0,2,5,7,8,10,13,15)$ 看起來很分散，其實只要兩圈：

```kmap
vars: [A, B, C, D]
ones: [0, 2, 5, 7, 8, 10, 13, 15]
groups:
  - [5, 7, 13, 15]
  - [0, 2, 8, 10]
caption: 四個角落 $m_0, m_2, m_8, m_{10}$ 兩兩只差一個位元，可以合成一圈。
```

角落那圈的四個最小項是 0000、0010、1000、1010，$B = 0$、$D = 0$ 都不變，所以是 $\inv{B}\,\inv{D}$。
:::

## 質蘊含項與必要質蘊含項

圈越大越好，但不是所有大圈都需要。先定義幾個名詞：

::: definition 蘊含項、質蘊含項、必要質蘊含項
- 蘊含項（implicant）：任何一個合法的圈。
- 質蘊含項（prime implicant）：已經不能再擴大的圈。
- 必要質蘊含項（essential prime implicant）：某個 1 只被這一個質蘊含項蓋到，所以它一定要選。
:::

化簡的標準流程是：

1. 找出所有質蘊含項。
2. 先選所有必要質蘊含項。
3. 若還有 1 沒被蓋到，用最少的質蘊含項補齊。

::: example 不是每個質蘊含項都要選
$F = \sum m(2,3,5,7)$ 有三個質蘊含項：

```kmap
vars: [A, B, C]
ones: [2, 3, 5, 7]
groups:
  - [2, 3]
  - [5, 7]
  - [3, 7]
partial: true
caption: 全部質蘊含項。這張圖只是列出候選，所以不寫最終式子。
```

$m_2$ 只被 $[2,3]$ 蓋到，$m_5$ 只被 $[5,7]$ 蓋到，所以這兩個是必要質蘊含項。選完之後 $m_3$ 和 $m_7$ 已經被蓋住，第三圈 $BC$ 就多餘了：

```kmap
vars: [A, B, C]
ones: [2, 3, 5, 7]
groups:
  - [2, 3]
  - [5, 7]
```

這正是上一單元的共識定理：$\inv{A}B + AC + BC = \inv{A}B + AC$。
:::

::: warning 先挑大圈不保證最簡
只靠「先圈最大的」容易多選一圈，像上例的 $BC$。照流程先挑必要質蘊含項，比較不會出錯。
:::

## 無關項

有些輸入組合永遠不會出現，例如用 4 個位元表示 0–9 的 BCD 碼時，1010–1111 不會出現。這些格子的輸出是 0 或 1 都無所謂，稱為無關項（don't care），在圖上記為 ×，寫成 $d(\ldots)$。

無關項的用法是：**能讓圈變大就當 1，否則當 0**，不需要全部圈到。

::: example $F = \sum m(1,3,7,11,15) + d(0,2,5)$

```kmap
vars: [A, B, C, D]
ones: [1, 3, 7, 11, 15]
dontcares: [0, 2, 5]
groups:
  - [3, 7, 11, 15]
  - [0, 1, 2, 3]
caption: 把 $m_0, m_2$ 當成 1，讓第一列湊成四格；$m_5$ 用不到就當 0。
```

把 $m_1$、$m_3$ 和 $m_5$、$m_7$ 圈成 $\inv{A}D$ 也一樣簡單，兩個答案都是最簡式。卡諾圖化簡的結果不一定唯一，只要項數與文字數都最少就對。
:::

## 圈 0 求最簡 POS

把 SOP 的方法反過來用：圈 0、讀成和項，再把和項 AND 起來。讀和項時，**不變的位元是 0 就寫原變數，是 1 就寫補數**，和最大項的規則一樣。

```kmap
vars: [A, B, C]
ones: [3, 5, 6, 7]
mode: pos
groups:
  - [0, 1]
  - [0, 2]
  - [0, 4]
caption: 多數決函數的 0 是 $m_0, m_1, m_2, m_4$。圈 $[0,1]$ 時 $A = 0$、$B = 0$ 不變，讀成 $(A + B)$。
```

同一個函數的最簡 SOP 是 $AB + AC + BC$，最簡 POS 是 $(A+B)(A+C)(B+C)$，兩者等價。實作時看哪一種用的閘比較少就選哪一種。

## NAND 與 NOR 實現

NAND 與 NOR 是通用閘，而且在 CMOS 中最省電晶體，所以化簡完的式子通常會轉成只用 NAND 或只用 NOR 的電路。

### 兩層 NAND：從 SOP 出發

SOP 是「AND 再 OR」。把整個式子取兩次補數，再用笛摩根定理拆開內層那一次：

$$F = AB + CD = \inv{\inv{AB + CD}} = \inv{\inv{AB} \cdot \inv{CD}}$$

$\inv{AB}$ 是 NAND，外層「AND 再取補數」也是 NAND。所以 **AND-OR 電路可以直接把每個閘換成 NAND**，連線完全不變。

::: example 用兩層 NAND 實現 $F(x,y,z) = \sum m(0,2,4,5,6)$
先化簡：

```kmap
vars: [x, y, z]
ones: [0, 2, 4, 5, 6]
groups:
  - [0, 2, 4, 6]
  - [4, 5]
```

$F = \inv{z} + x\inv{y}$。第二項 $x\inv{y}$ 換成 NAND，第一項只有一個文字，它進入外層 NAND 前要先取補數，也就是直接接 $z$：

$$F = \inv{\,z \cdot \inv{x\inv{y}}\,}$$

共用一個兩輸入 NAND（輸入 $x$、$\inv{y}$）和一個兩輸入 NAND 輸出級，$\inv{y}$ 由反相器提供。
:::

::: warning 單一文字項要反相
SOP 中只有一個文字的項，直接接到輸出級 NAND 時要先取補數。上例的 $\inv{z}$ 在 NAND 電路裡變成接 $z$；如果項是 $z$，就要接 $\inv{z}$。
:::

### 兩層 NOR：從 POS 出發

對偶地，POS 是「OR 再 AND」，**把每個閘換成 NOR** 即可。要用 NOR 實現，就先在卡諾圖上圈 0 得到最簡 POS。

上例的 0 是 $m_1, m_3, m_7$，圈 $[1,3]$ 得 $(x + \inv{z})$，圈 $[3,7]$ 得 $(\inv{y} + \inv{z})$，所以

$$F = (x + \inv{z})(\inv{y} + \inv{z}) = \inv{\,\inv{x + \inv{z}} + \inv{\inv{y} + \inv{z}}\,}$$

### 多層電路的轉換

式子超過兩層時，用「泡泡」（小圓圈，代表反相）來轉換：

1. 每個 AND 換成 NAND（AND 加輸出泡泡）。
2. 每個 OR 換成「輸入加泡泡的 OR」，它等於 NAND（笛摩根定理）。
3. 檢查每條線：兩端泡泡成對就互相抵消；只有一個泡泡的地方要補一個反相器，或把輸入變數改接補數。

NOR 電路的做法相同，只是角色互換：OR 換成 NOR，AND 換成「輸入加泡泡的 AND」。

## 其他兩層實現

AND、OR、NAND、NOR 兩兩組成兩層電路共有 16 種。其中 8 種會退化成單一運算（例如 AND-AND 只是一個多輸入 AND），另外 8 種是非退化形式（nondegenerate form），分成四組等價的對：

| 等價形式 | 實現的函數 | 怎麼化簡 |
| --- | --- | --- |
| AND-OR、NAND-NAND | $F = AB + CD$（SOP） | 圈 1 得 $F$ |
| OR-AND、NOR-NOR | $F = (A+B)(C+D)$（POS） | 圈 0 得 $F$ |
| AND-NOR、NAND-AND | $F = \inv{AB + CD}$（AND-OR-INVERT, AOI） | 圈 0 得 $\inv{F}$ 的 SOP |
| OR-NAND、NOR-OR | $F = \inv{(A+B)(C+D)}$（OR-AND-INVERT, OAI） | 圈 1 得 $F$ 的 SOP，取補數成 $\inv{F}$ 的 POS |

AOI 與 OAI 在 CMOS 中可以做成單一複合閘，比分開的 AND、OR 加反相器更省面積與延遲。

## 互斥或與同位元

### XOR 的性質

$x \oplus y = x\inv{y} + \inv{x}y$，XNOR 是它的補數 $\inv{x \oplus y} = xy + \inv{x}\,\inv{y}$。常用的性質：

- $x \oplus 0 = x$、$x \oplus 1 = \inv{x}$
- $x \oplus x = 0$、$x \oplus \inv{x} = 1$
- $x \oplus \inv{y} = \inv{x} \oplus y = \inv{x \oplus y}$
- 滿足交換律與結合律，所以 $x \oplus y \oplus z$ 不必加括號。

### 奇函數

多變數 XOR 在奇數個輸入為 1 時輸出 1。三變數 XOR 是 $\sum m(1,2,4,7)$，在卡諾圖上呈棋盤狀，**沒有任何兩個 1 相鄰**，所以無法用 SOP 化簡，直接用 XOR 閘最省：

```kmap
vars: [x, y, z]
ones: [1, 2, 4, 7]
caption: 三變數奇函數 $x \oplus y \oplus z$。四個 1 互不相鄰，卡諾圖化簡不了。
```

XNOR 則是偶函數，在偶數個輸入為 1 時輸出 1。

### 同位元產生器與檢查器

傳送 3 位元訊息 $x, y, z$ 時，用偶同位：發送端的同位元產生器（parity generator）算出 $P = x \oplus y \oplus z$，讓四個位元中 1 的個數為偶數。接收端的同位元檢查器（parity checker）計算

$$C = x \oplus y \oplus z \oplus P$$

$C = 0$ 表示沒有偵測到錯誤，$C = 1$ 表示有奇數個位元出錯。這就是[第 1 單元](01-number-systems.html)同位元的電路實現。

## 重點整理

- 卡諾圖用格雷碼排列，讓只差一個位元的最小項在圖上相鄰，邊界與角落也相鄰。
- 圈的格數必須是 $2^k$ 且為矩形，圈 $2^k$ 格消掉 $k$ 個變數。
- 圈內不變的變數留下，變化的變數消掉。
- 化簡流程：找出所有質蘊含項 → 選必要質蘊含項 → 用最少的質蘊含項補齊。
- 無關項能讓圈變大就當 1，否則忽略。
- 圈 0 得到最簡 POS，讀和項時 0 寫原變數、1 寫補數。
- SOP 的 AND-OR 可直接換成 NAND-NAND，POS 的 OR-AND 可直接換成 NOR-NOR；單一文字項要反相。
- 非退化兩層形式共 8 種，AOI 圈 0 得 $\inv{F}$ 的 SOP，OAI 圈 1 再取補數。
- 多變數 XOR 是奇函數，卡諾圖呈棋盤狀無法化簡；偶同位產生器 $P = x \oplus y \oplus z$。

## 練習題

:::: exercise 求 $F(A,B,C) = \sum m(0,1,2,5)$ 的最簡 SOP
::: answer
先找質蘊含項：$[0,1]$ 讀成 $\inv{A}\,\inv{B}$，$[0,2]$ 讀成 $\inv{A}\,\inv{C}$，$[1,5]$ 讀成 $\inv{B}C$。

$m_2$ 只能被 $[0,2]$ 蓋到，$m_5$ 只能被 $[1,5]$ 蓋到，兩者都是必要質蘊含項。選完後 $m_0$、$m_1$ 也被蓋住，$[0,1]$ 不需要：

```kmap
vars: [A, B, C]
ones: [0, 1, 2, 5]
groups:
  - [0, 2]
  - [1, 5]
caption: $m_0$ 和 $m_2$ 分別在最左欄與最右欄，跨越左右邊界相鄰。
```
:::
::::

:::: exercise 求 $F(A,B,C,D) = \sum m(0,1,2,4,5,6,8,9,12,13,14)$ 的最簡 SOP
::: answer
左邊兩欄（$CD = 00, 01$）全部是 1，可以圈成 8 格，消掉 3 個變數得到 $\inv{C}$。剩下 $m_2$、$m_6$、$m_{14}$ 在最右欄（$CD = 10$），利用左右邊界相接和最左欄的 1 合成四格圈：

```kmap
vars: [A, B, C, D]
ones: [0, 1, 2, 4, 5, 6, 8, 9, 12, 13, 14]
groups:
  - [0, 1, 4, 5, 8, 9, 12, 13]
  - [0, 2, 4, 6]
  - [4, 6, 12, 14]
```

$[0,2,4,6]$ 中 $A = 0$、$D = 0$ 不變，讀成 $\inv{A}\,\inv{D}$；$[4,6,12,14]$ 中 $B = 1$、$D = 0$ 不變，讀成 $B\inv{D}$。
:::
::::

:::: exercise 求 $F(A,B,C,D) = \sum m(0,1,2,5,8,9,10)$ 的最簡 POS
::: answer
函數的 0 是 $m_3, m_4, m_6, m_7, m_{11}, m_{12}, m_{13}, m_{14}, m_{15}$，改成圈 0：

```kmap
vars: [A, B, C, D]
ones: [0, 1, 2, 5, 8, 9, 10]
mode: pos
groups:
  - [12, 13, 14, 15]
  - [3, 7, 11, 15]
  - [4, 6, 12, 14]
```

- $[12,13,14,15]$：$A = 1$、$B = 1$ 不變 → $(\inv{A} + \inv{B})$。
- $[3,7,11,15]$：$C = 1$、$D = 1$ 不變 → $(\inv{C} + \inv{D})$。
- $[4,6,12,14]$：$B = 1$、$D = 0$ 不變 → $(\inv{B} + D)$。

三個和項 AND 起來就是最簡 POS。
:::
::::

:::: exercise 化簡 $F(A,B,C,D) = \sum m(0,1,2,8,9,10)$，並畫成兩層 NAND 電路
::: answer
```kmap
vars: [A, B, C, D]
ones: [0, 1, 2, 8, 9, 10]
groups:
  - [0, 1, 8, 9]
  - [0, 2, 8, 10]
caption: 第一圈跨上下邊界，第二圈是四個角落。
```

$F = \inv{B}\,\inv{C} + \inv{B}\,\inv{D}$。兩層 NAND：

$$F = \inv{\,\inv{\inv{B}\,\inv{C}} \cdot \inv{\inv{B}\,\inv{D}}\,}$$

需要兩個兩輸入 NAND（輸入分別是 $\inv{B}, \inv{C}$ 和 $\inv{B}, \inv{D}$），加一個兩輸入 NAND 當輸出級，$\inv{B}, \inv{C}, \inv{D}$ 由反相器提供。

若允許多層，提出 $\inv{B}$ 得 $F = \inv{B}(\inv{C} + \inv{D}) = \inv{B}\,\inv{CD} = \inv{B + CD}$，只要一個 AND 和一個 NOR，閘數更少。
:::
::::

:::: exercise 用偶同位傳送 4 位元資料 $1011$，同位元是多少？若收到 $1001$ 加同位元 $1$，檢查器輸出為何？
::: answer
同位元 $P = 1 \oplus 0 \oplus 1 \oplus 1 = 1$，傳送的 5 個位元中有四個 1，是偶數。

收到 $1001$ 與 $P = 1$：$C = 1 \oplus 0 \oplus 0 \oplus 1 \oplus 1 = 1$，1 的個數是奇數，檢查器輸出 1，表示偵測到錯誤（原本的第三位在傳送中翻轉了）。
:::
